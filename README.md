# Homebrew tap for RustTorrent

```bash
brew install --cask manojknaikade/tap/rusttorrent
```

Installs [RustTorrent](https://github.com/manojknaikade/RustTorrent), a small torrent client for Apple Silicon Macs.

The app is signed only locally, not by an Apple developer account, so the install removes the download mark that would make macOS refuse to open it.
